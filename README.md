# 星之卡比同人游戏

一款基于 **Qt 6** 开发的 2D 横版平台跳跃动作游戏，融合了卡比系列的吸入复制能力机制与泰拉瑞亚风格的 Boss 战。

## 快速开始

打开 `release` 文件夹，双击 **Kirby.exe** 即可启动游戏。

> 确保 `release` 目录下的 Qt6 运行库 DLL 文件与 exe 保持在同一文件夹内。

## 游戏内容

### 游戏模式

| 模式 | 说明 |
|------|------|
| **冒险模式** | 完整横版关卡，跨越多种地形与生态区域，沿途有敌人、收集品、存档点和终点旗帜 |
| **Boss 战** | 三场独立 Boss 战，可选择挑战克苏鲁之脑、猪鲨公爵或冰之神 |
| **继续游戏** | 从最近的检查点恢复冒险进度 |

### 核心机制 — 复制能力

按住 **L** 键吸入特定敌人，再按 **L** 消化后可获得其能力。已收集的能力存入能力池（最多 2 个），按 **R** 键切换，按 **T** 键取消当前形态。

| 能力 | 来源敌人 | 主动技能 (J) | 被动效果 |
|------|----------|-------------|----------|
| **火焰** | 火系敌人 | 按住 J 火焰冲刺（速度翻倍），再按 J 爆炸（大范围 50 伤害，摧毁碎石、融化冰块） | 冲刺碰触融化冰块、摧毁碎石 |
| **冰冻** | 冰系敌人 | 长按 J 开启冰之防御（5 秒无敌，冻结附近水面为冰块） | 防御期间免疫伤害 |
| **叶片** | 草系敌人 | 按 J 发射羽毛飞弹（30 伤害） | 远程攻击 |
| **闪电** | 电系敌人 | 按 J 切换自由飞行模式（八向移动），飞行中按 K 冲刺 | 基础移速提升 50% |

### Boss 介绍

- **克苏鲁之脑**：二阶段传送追踪型 Boss，半血后进入狂暴模式，高速追击并加快弹幕频率
- **猪鲨公爵**：三阶段 Boss，二阶段将地面转化为水域并释放螺旋弹幕，三阶段连续冲锋
- **冰之神**：召唤雪花仆从、释放冰锥、冰束和冰雨的范围压制型 Boss

### 场景交互

- **水体**：减缓移动，消耗耐力游泳；耐力耗尽会溺水
- **冰块**：可被火焰能力融化
- **碎石块**：可被火焰爆炸摧毁
- **可推木箱**：用于垫脚解谜，可浮于水面
- **尖刺**：多种尖刺陷阱（固定、移动、伏击），碰触即受伤
- **蛋糕**：吸入后获得 20 秒远程攻击能力
- **星星**：吸入或碰触收集，作为星弹消耗使用

## 操作说明

### 移动

| 按键 | 动作 |
|------|------|
| `A` / `←` | 向左移动 |
| `D` / `→` | 向右移动 |
| `W` / `↑` | 跳跃（地面）/ 浮空（空中）/ 上浮（水中） |
| `S` / `↓` | 向下移动（闪电飞行模式） |

### 动作

| 按键 | 动作 |
|------|------|
| `J` | 攻击（火焰冲刺、冰之防御、羽毛射击、闪电飞行开关） |
| `K` | 翻滚 / 闪电冲刺（飞行中） |
| `L` | 吸入（靠近敌人/道具时按住）/ 消化获得能力 / 长按 1 秒取消当前形态 |
| `T` | 星弹吐出（胖子形态）/ 瞬间取消当前复制能力 |
| `U` | 消耗星星库存发射星弹 |
| `R` | 切换到下一个已收集的复制能力 |
| `.` `,` | 顺时针/逆时针旋转瞄准角度（Boss 战） |
| `Escape` | 暂停 / 返回上级菜单 |

## 构建说明

本项目使用 **Qt 6.11.0** + **MinGW 64-bit** + **qmake** 构建。

1. 使用 Qt Creator 打开 `kirby.pro`
2. 配置 MinGW 64-bit 构建套件
3. 编译运行

依赖模块：`core` `gui` `widgets` `multimedia`
